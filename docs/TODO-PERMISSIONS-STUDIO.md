# Permissions Studio — Backlog

Status: Planned after Server Duplicator permission-copy reliability is confirmed.

Goal: Build a bulk Discord category/channel permission editor for Goliath.

Planned scope:
- Bulk select categories/channels and one or more roles.
- Discord-style tri-state Allow / Neutral / Deny editing.
- Apply permission changes across many targets at once.
- Per-category and per-channel role overrides.
- Copy permissions from one category/channel to many others.
- Sync child channels to category permissions.
- Bulk add/remove role overwrites.
- Merge vs replace overwrite modes.
- Permission presets and saved custom presets.
- Dry-run / preview before applying.
- Automatic backup and undo for bulk changes.
- Role base/advanced permission editor.
- Share the same permission engine with Server Duplicator so copied permissions and manually edited permissions use one implementation.
